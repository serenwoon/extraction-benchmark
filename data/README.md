# data/ — 출처와 라이선스

## 원본

`raw.html` — **위키문헌 「대한민국 도로교통법」** 문서를 2026-08-10에 내려받은 것.
<https://ko.wikisource.org/wiki/대한민국_도로교통법>

위키문헌은 갱신되므로, 이 저장소의 결과를 재현하려면 **이 파일을 쓴다.** 지금 다시 받으면 조문이 다를 수 있다.

## 라이선스 두 층

법령 본문은 저작권법 제7조에 따라 보호받지 못하는 저작물이라 자유롭게 쓸 수 있다. 반면 `raw.html`의 편집과 구조와 서식은 위키문헌의 것이고 CC BY-SA 4.0이 붙는다. 출처 표시와 동일조건변경허락이 조건이다.

파생물인 `articles.json`과 `sample_10.json`은 법령 본문만 추출한 것이다.

## 파일

| 파일 | 무엇 |
|---|---|
| `raw.html` | 내려받은 원본 (재현용 고정본) |
| `articles.json` | 조문 210개 파싱 결과 |
| `sample_10.json` | 표본 10건 (`random.seed(20260810)`) |
| `golden_human.json` | 사람이 AI 없이 채운 답 — **골든셋** |
| `pipeline_10*.json` | 파이프라인 실행 결과 (3회 + 스모크 1회) |
| `timing.json` · `score.json` · `clause_check.json` | 측정·채점 결과 |

`golden_human.json` 은 **1인 1회**의 라벨이다. 정답의 표준이 아니라 *이 측정에서만 쓰는 기준*이다. 한계는 최상위 README에 적어뒀다.
